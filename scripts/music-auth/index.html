Apple Music setup

Create a user token for your GitHub Action. Your private key is used in this browser to sign a short-lived developer token. It is not uploaded or saved by this tool.

Or paste the private key

Pasted text takes precedence over the selected file and is cleared after signing.

If Apple only offers “Try Apple Music”, open Apple Music on the web in this browser and confirm you can sign in and play a full song with your subscription. Then close the authorization window and retry here. Allow pop-ups for this local page.

Your Music User Token

Save this value in your repository under Settings → Secrets and variables → Actions → New repository secret, named APPLE_MUSIC_USER_TOKEN.

Close this page when finished. MusicKit may remember your authorization in this browser.
